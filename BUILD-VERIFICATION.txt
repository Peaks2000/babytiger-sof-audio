Offline checks
  Patch applied cleanly to the Fedora baseline. The external source matched
  the in-tree result except for the local DA7219 header include.
  checkpatch.pl --no-tree --no-signoff: 0 errors, 0 warnings.
  The Makefile rejected the host's 7.2.15-200.fc44.x86_64 development tree.
  In an isolated module tree extracted from signed Fedora RPMs, depmod and
  modinfo selected the override under updates/babytiger. modprobe
  --show-depends resolved the BXT alias and its dependencies without loading
  anything. After removing the override and re-running depmod, modinfo again
  selected the stock .ko.xz.
  Bash syntax checks passed for all scripts. The installer fixture checked
  NHLT route and checksum rejection, rejection of the old lock marker and
  conflicting configuration, install, rollback and initramfs failure recovery.
  It verified that rollback and a failed rebuild retain the guard files and
  that the installer rejects a generated image that lacks the lock or contains
  an amp module.
  Actual dracut 108 and lsinitrd checks used scratch generic images in an
  isolated user and mount namespace for Fedora 45 7.3.3-300 and Fedora 44
  7.2.15-200. A fixture requested both MAX98357A modules and the DA7219 codec.
  Control images contained all three. Guarded images contained DA7219 and
  the exact modprobe lock file, and excluded both MAX98357A modules. These
  images were never booted and no installed initramfs was changed.
  A kmod dry run against the Fedora 45 stock modules with the lock in place
  resolved explicit modprobe requests for both amp modules to /usr/bin/false.
  Fedora 45 alsa-sof-firmware-2026.09.2-1.fc45.noarch passed signature checks.
